# Criterion: dchi2_truth = chi2(point lens) - chi2(EXACT truth) < 10, where
# both are minimized over (t_0, u_0, t_E, alpha) with rho optimized, the
# point lens being q = 1e-8 at the truth's s.  A planet the data cannot
# distinguish from a point lens cannot be recovered by any search, so these
# are not tests of the method.  Measured by job 52114785 (dc18_truth_detect.py).
#
# THRESHOLDS -- k = 3 extra parameters (s, q, alpha):
#   CURRENT   dchi2 < 10   (2.35 sigma, p = 0.019)  -> 7 removed, 23 kept
#   PLANNED   dchi2 <  5   (1.37 sigma, p = 0.17)   -> 5 removed, 25 kept
#             relax to 5 once the pipeline is working well at 10 (JDE).
#   for reference: 3 sigma at k = 3 is dchi2 = 14.16 (9.00 only at k = 1).
# Deliberately LENIENT: a false positive costs one fit, while a high bar
# discards recoverable planets.  The opposite of events_moving.txt, where
# a high bar is the conservative choice.  The sigma labels assume Wilks'
# theorem, which planet detection violates (q -> 0 is a boundary; s, alpha
# unidentifiable there), so they are optimistic; fine for choosing test
# cases, not for claiming detections.
